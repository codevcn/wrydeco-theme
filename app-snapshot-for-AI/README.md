# Tài liệu cho AI đọc hiểu website

Thư mục này dùng để lưu trữ các file snapshot của website cho AI đọc hiểu. Ví dụ:

- Bối cảnh kinh doanh và yêu cầu coding của website: `./business-context-and-requirements/`
- Styling chủ đạo của website qua các ảnh chụp màn hình: `./main-styling-by-screenshots/`

Các tệp này nên được AI đọc trước khi trả lời để thiết kế hay coding chuẩn hơn cho website.
