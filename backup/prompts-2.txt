Tôi đang test tính năng "write a review" cho trang web Wrydeco của tôi, bạn hãy viết 1 prompt yêu cầu Google Flow tạo ảnh review sản phẩm trong ảnh đính kèm này.
Trong prompt phải yêu cầu rõ là ảnh review phải chân thật, nhìn ko giống AI tạo, nhìn ảnh như con người tự chụp, ảnh chụp nhiều góc khác nhau, thời gian chụp ảnh có thể là ban ngày hoặc ban đêm. Đảm bảo sản phẩm trong ảnh review phải giống 100% sản phẩm trong ảnh đính kèm, ko thay đổi bất cứ chi tiết nào của sản phẩm trong ảnh đính kèm.


Ảnh đính kèm này là ảnh kết quả từ google flow, nhìn nó vẫn còn khá giống ảnh AI, bạn hãy cải thiện prompt mạnh hơn để tạo ảnh đúng ý muốn hơn.


Thực thi yêu cầu được nêu trong file todo.images.md (đã cập nhật file config)


Thực thi yêu cầu được nêu trong file todo.images.md (đã cập nhật file config & file todo.images.md), lưu ý là thực thi yêu cầu trong file **todo.images.md** chứ ko phải file todo.md nhé! Khi xong việc, hãy chạy lệnh CLI "mod toast {message muốn thông báo}" để thông báo cho tôi biết.
