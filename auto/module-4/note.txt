1. Đọc toàn bộ file `./human-reviews.md` để biết cách hành văn viết các review sản phẩm cho giống người bản xứ.
2. Đọc file `./template.csv` để biết cấu trúc viết review trong file CSV.
3. Giải thích cấu trúc file `./config.json`:

- 1 sản phẩm được khai báo trong file config như sau:

```json
{
  "id": "8355494133817",
  "handle": "handmade-solid-wood-tree-branch-bookshelf-wall-decor",
  "image_local_file_paths": [
    "assets/images/products/handmade-solid-wood-tree-branch-bookshelf-wall-decor.jpg"
  ]
}
```

- Giải thích các field trong 1 sản phẩm:
  - `id`: ID của sản phẩm trên store.
  - `handle`: Handle của sản phẩm trên store.
  - `image_local_file_paths`: Danh sách các file path của ảnh review sản phẩm tại local. Mỗi sản phẩm có thể có nhiều ảnh, nhưng không bắt buộc phải có ảnh. Nếu không có ảnh thì field này sẽ rỗng hoặc ko tồn tại.

4. Với mỗi sản phẩm được khai báo trong file `./config.json`, bạn hãy thực hiện các bước sau:

- Bước 1 (BẮT BUỘC): Truy cập vào store Wrydeco bằng `./access-token.md` để đọc thông tin chi tiết của sản phẩm để viết review bám sát sản phẩm hơn, thay vì viết review chung chug.
- Bước 2 (BẮT BUỘC): Đọc từng file path của ảnh review sản phẩm được liệt kê trong field `products.images_file_paths_to_add_into_csv` để lấy thông tin hình ảnh.
- Bước 2: Chạy file `./auto/module-4/write_ratings_by_star.cmd` để lấy chỉ tiêu số lượng sao từ 1 đến 5 sao cho các review.
- Bước 3: Đọc file `./reviews-rule.txt` để xác định chỉ tiêu tạo ra các review.
- Bước 4: Hãy đóng vai 1 người thường xuyên đặt hàng online để viết reviews (cho sản phẩm đã đọc được thông tin) vào file `./output/{product_id}-reviews.csv` dựa theo chỉ tiêu đã xác định và thông tin hình ảnh đã lấy được (chỉ tạo reviews trong file CSV trong folder "output", ko tạo file bên ngoài folder này).
- Bước 5: Sau khi viết reviews trong file CSV xong, lặp lại các bước trên cho các sản phẩm còn lại.

5. Sau khi viết xong reviews thì thêm thông tin sản phẩm và thông tin tạo review vào cuối file `./handled.json` (ko xóa nội dung hiện có).
6. Chạy file `./clean.cmd` để xóa các file tạm thời và các file không cần thiết.
7. Chạy file `./merge_csv.cmd` để gộp tất cả các file CSV reviews của các sản phẩm vào 1 file CSV duy nhất.
8. Viết báo cáo kết quả tạo reviews cho các sản phẩm vào file `./report.md`.
9. Khi xong việc, hãy chạy lệnh CLI `mod toast {message muốn thông báo}` để thông báo cho tôi biết.
