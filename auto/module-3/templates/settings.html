Cấu hình Shopify App Riêng cho Trang Cập nhật Logo (Kích hoạt khi Bật Proxy)

Đang dùng mặc định server (Loại 1)
Cơ chế hoạt động: Bộ credentials này (Client ID, Client Secret, Access Token) chỉ được áp dụng khi trang Cập nhật logo BẬT kết nối Proxy Gateway. Khi TẮT Proxy, trang sẽ bắt buộc fallback 100% về sử dụng credentials mặc định của server từ file .env (kết nối trực tiếp từ VPS).

Để trống sẽ sử dụng store mặc định của server (wrydeco.myshopify.com).

Client ID của App được cấp quyền trong Shopify Partner/Admin.

Client Secret của App (để trống nếu không muốn thay đổi).

Bắt buộc để gọi Admin REST & GraphQL API (để trống nếu không đổi).
